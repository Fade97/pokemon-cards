A: Binder (Sleevebook)

Each set is a binder page of 3×3 sleeve pockets. Cards you own sit in their pocket, and each missing card is an empty pocket showing its number. Colors are bottle green with brass.

B: Slab (Casebook)

Every card sits in a graded-card case, and the yellow label carries its data and price. The collection's total value leads the collections screen, and each set appears as a label strip with a completion bar.

C: Index (Setlist)

The collector number is the main type. Each set is a grid of all its slots, filled in the card's energy color when owned, so you can see at a glance what's missing.

D: Booster (Pullstack)

Scanning feels like opening a pack: each match pops onto a stack. Sets are round stamps that fill up as you complete them, drawn chunky, bright and with hard shadows.
