# 0009. Neutral name; card art not bundled

Status: accepted (2026-11-15)

## Context

Google Play bans trademark confusion, and the card art is copyrighted by TPC.

## Decision

The name is a neutral TCG/binder name with no Pokéball, and store text carries a disclaimer of no affiliation; a trademark check happens before the listing. Images load from the TCGdex CDN with a local cache, and the user's scan can replace the image.

## Alternatives considered

Name containing 'Poké'; mirroring images on our own R2; showing only user photos.
